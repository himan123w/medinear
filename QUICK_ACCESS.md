## 🚀 Quick Start

1. **Open Frontend**: http://localhost:5173
2. **Login** with one of the test accounts above
3. **Explore Features**:
   - Search medicines
   - Find nearby pharmacies
   - Upload prescriptions
   - Create reservations
   - Track deliveries
   - Manage subscriptions

---

## 🔧 Server Management

### Start Backend
```bash
npm start
```

### Start Frontend
```bash
cd medinear-frontend
npm start
```

### Seed Database
```bash
npm run seed
```

### Add Test Users
```bash
node add-test-users.js
```
