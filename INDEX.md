## 📚 Documentation by Role

3. Run `./start.sh` to launch
4. Visit http://localhost:5173

**Development**
- Backend: `npm run dev` (auto-reload with nodemon)
- Frontend: `npm start` (hot reload with Vite)
- API: http://localhost:5001/api
